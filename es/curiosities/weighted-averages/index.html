El promedio no vive en ningún lado

Curiosidad · Encuesta Intercensal 2025

Un promedio nacional le da el mismo peso a cada persona. Eso lo vuelve una cifra correcta sobre el país y una mala descripción de casi cualquiera de sus pedazos. La nueva encuesta intercensal deja ver la distancia, municipio por municipio.

Curiosidad · INEGI, Encuesta Intercensal 2025 · Microdatos públicos

Un promedio nacional le da el mismo peso a cada persona. Eso es justo lo que lo vuelve la cifra correcta para una pregunta sobre personas, y la equivocada para una pregunta sobre lugares. Si la mitad de la gente de un país vive en unas cuantas ciudades grandes, el promedio nacional se parece a esas ciudades. No se parece al pueblo típico.

Son dos cantidades distintas. Un promedio ponderado por población responde qué le pasa a la persona promedio; un promedio entre lugares responde qué pasa en el lugar promedio. Casi siempre se calcula el primero y se cuenta como si fuera el segundo. Pueden estar a treinta puntos de distancia.

La Encuesta Intercensal 2025, publicada en septiembre de 2026, deja ver la distancia con facilidad. Entrevistó alrededor de siete millones de viviendas, que alcanzan para estimar por separado cada uno de los 2,478 municipios del país.

Antes del mapa: el país entero

La encuesta pregunta por siete prestaciones laborales, y solo se las pregunta a quien trabaja para un patrón (no a quien trabaja por cuenta propia, a quien nunca se le planteó la pregunta). Entre esas 40.9 millones de personas, así queda el país:

Dos cosas saltan antes de cualquier geografía. El reparto de utilidades queda al final con 42.7% y el aguinaldo encabeza con 64.2%, y los dos son obligaciones de ley, no concesiones del patrón. Que veintidós puntos separen dos derechos que la ley trata igual dice menos sobre lo que la ley ordena que sobre lo que se cumple y sobre lo que la gente sabe que le toca.

Ahora el mapa

Todo lo anterior son promedios de personas. El mapa cambia la unidad: cada polígono es un municipio y todos pesan igual, vivan ahí dos mil habitantes o dos millones.

// La función de la gráfica NO lee el selector: recibe la clave, la etiqueta y el
// esquema. Es la forma que ya usan data-informality.qmd y la curiosidad de mascotas.
graficaMapa = (clave, etiqueta, esquema, { width = 700 } = {}) => {
  const valor = f => {
    const d = porCvegeo.get(f.properties.CVEGEO);
    return d ? d[clave] : undefined;
  };
  const impreciso = f => {
    const d = porCvegeo.get(f.properties.CVEGEO);
    return d ? d["p_" + clave] === 0 : false;
  };
  const figura = Plot.plot({
    width, height: Math.round(width * 0.62),
    projection: { type: "mercator", domain: { type: "FeatureCollection", features: munFeatures } },
    style: { background: "transparent", fontFamily: "IBM Plex Sans, sans-serif", fontSize: "12px", color: "var(--ink)" },
    color: {
      type: "quantize", n: 7, scheme: esquema, domain: [0, 0.9],
      label: etiqueta, legend: true, tickFormat: d => (100 * d).toFixed(0) + "%",
      unknown: "transparent"
    },
    marks: [
      Plot.geo(munFeatures, {
        fill: valor, stroke: "var(--rule)", strokeWidth: 0.12, tip: true,
        title: f => {
          const d = porCvegeo.get(f.properties.CVEGEO);
          if (!d) return `${f.properties.NOMGEO}\nmuestra insuficiente`;
          const v = d[clave];
          return `${d.municipio}, ${d.entidad}\n${etiqueta}: ${(100 * v).toFixed(1)}%` +
                 (d["p_" + clave] === 1 ? "" : "  (imprecisa)");
        }
      }),
      Plot.geo(munFeatures.filter(impreciso), { fill: "url(#rayas)", stroke: "none" }),
      Plot.geo(fronterasEstatales, { stroke: "var(--ink)", strokeWidth: 0.45, strokeOpacity: 0.4 }),
      Plot.geo(contornoPais, { stroke: "var(--ink)", strokeWidth: 0.7, strokeOpacity: 0.65 })
    ]
  });
  // El rayado va como patrón SVG inyectado después de que Plot arma la figura.
  const svg = figura.tagName === "svg" ? figura : figura.querySelector("svg");
  const defs = d3.select(svg).insert("defs", ":first-child");
  defs.append("pattern")
    .attr("id", "rayas").attr("width", 3.2).attr("height", 3.2)
    .attr("patternUnits", "userSpaceOnUse").attr("patternTransform", "rotate(45)")
    .append("line")
      .attr("x1", 0).attr("y1", 0).attr("x2", 0).attr("y2", 3.2)
      .attr("stroke", "var(--plot-background)").attr("stroke-width", 1.3).attr("stroke-opacity", 0.85);
  return figura;
}

Cada punto es uno de los 2,471 municipios con estimación. El dato nacional queda por encima de de cada 100 de ellos. En el aguinaldo, el municipio de en medio está en 33.8% contra un nacional de 64.2%: treinta puntos de distancia, y no es un error de cálculo. El dato nacional pesa personas; el mapa pesa lugares.

Por qué hay municipios rayados

Una estimación de encuesta trae error de muestreo, y la forma habitual de resumirlo es el coeficiente de variación: el error estándar dividido entre la estimación misma. INEGI publica un dato municipal cuando ese cociente no pasa de 15% y lo reserva cuando lo pasa. Es un criterio razonable y aquí es una trampa.

El coeficiente de variación lleva la estimación en el denominador, así que crece solo cuando la cobertura es baja, aunque el error no cambie. En estos datos la correlación entre cobertura y coeficiente de variación es −0.61. Ordenando los municipios en cinco grupos según su precisión, la cobertura mediana del aguinaldo cae de 65% en el grupo más preciso a 12% en el menos preciso, y de ese último grupo solo el 13% pasa el corte de 15%.

Entonces ocultar las estimaciones imprecisas no quita ruido repartido al azar. Quita, casi exactamente, a los municipios donde la prestación es más rara. El mapa quedaría más limpio y diría algo falso. Ocultarlas subiría la mediana municipal entre 5.3 y 8.9 puntos según la prestación; en el reparto de utilidades, la mediana pasaría de 10.8% a 19.7%, casi el doble, sin que ningún número estuviera mal calculado.

Por eso este mapa las pinta, y conviene separar dos lecturas. Municipio por municipio, el rayado sí quiere decir que la estimación es débil: el intervalo es ancho y el número no aguanta que se le cite por su cuenta. En conjunto, en cambio, los rayados no son una muestra al azar de municipios, sino que se concentran donde la cobertura es baja. Quitarlos no quitaría ruido: correría la lectura del país hacia arriba. La regla práctica es no citar un municipio rayado por separado, y no leer las zonas rayadas como territorio sin información.

Cómo está hecho

Fuente: INEGI, Encuesta Intercensal 2025; microdatos publicados el 22 de septiembre de 2026. Universo: personas de 15 años o más, ocupadas y subordinadas, es decir que trabajan para un patrón. La encuesta solo hace estas siete preguntas a ese grupo, así que esto no mide informalidad y no es comparable con la tasa que publica la ENOE. Estimación con el diseño muestral de la propia encuesta: muestreo en una sola etapa, estratificado y por conglomerados, con los estratos y unidades primarias que publica INEGI. Las medianas municipales de esta página se calculan sobre los 2,471 municipios con estimación, no solo sobre los precisos, por la razón que explica la sección anterior. Geometría: el Marco Geoestadístico de la misma Encuesta Intercensal 2025, con los 2,478 municipios vigentes al levantamiento; siete quedan sin color porque INEGI no alcanzó ahí la cobertura mínima y solo difunde vivienda y población.
